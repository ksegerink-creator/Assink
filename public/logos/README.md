# Logo's

Plaats hier het **officiële Assink & Schipholt logo**. Verwacht:

- `assink-schipholt.svg` — primair logo (kleur)
- `assink-schipholt-white.svg` — negatief/wit logo voor donkere vlakken (footer, hero-band)

Zolang deze bestanden ontbreken, toont de header/footer een duidelijk gemarkeerde
logopositie. Vervang de placeholder door het echte logo in
`src/components/navigation/Logo.astro`.

> Het logo is **niet** opnieuw ontworpen. Gebruik uitsluitend het officiële,
> door het bedrijf aangeleverde logo.
